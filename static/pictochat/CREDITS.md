# Credits for the files in this folder

The PictoChat page on this site (`/projects/pictochat/`) is built to look like the
browser PictoChat client "PictoChat Online" by ayunami2000, and these files come from it:

- `images/*.png` — the screen, keyboard, bubble and button sprites.
  Source: https://github.com/ayunami2000/ayunpictojava (`src/main/resources/www/images/`)
- `nds.ttf` — a Nintendo DS-style pixel font, "Copyright caveras 2016".
  Source: the same repository (`src/main/resources/www/nds.ttf`)

- `sounds/*.mp3` — the 20 sound effects (keys, pens, sending, joining, and so on).
  Source: the same repository (`src/main/resources/www/sounds/`). These sound like the
  sounds from Nintendo's PictoChat, so they are very likely Nintendo's recordings.

Only the files above were copied. All of the code on the page is original.

## Rights

The source repository has no license file, so I don't have explicit permission to
redistribute these files. They also imitate the look and sound of Nintendo's PictoChat,
which is Nintendo's. The sounds are the part most likely to be Nintendo's own material. They are kept in this one folder so they are easy to remove or replace.
If either author (or Nintendo) asks for them to be taken down: delete this folder and
swap in your own sprites and sounds. The page works without the sounds: if they fail
to load, it simply stays quiet.
